# 同步数据申请步骤

## MARS / REACT 2026：优先申请四模态版本

官方仓库：https://github.com/reactmultimodalchallenge/baseline_react2026

本目录MARS/EULA_MARS_dataset.pdf是从该仓库下载的原始协议文件，未代为填写或签署。由你和指导老师阅读条款、按要求签署后，按仓库说明向s.song@exeter.ac.uk提交。这里仅提供流程，不代表已获授权。

申请中说明：本科大创，研究同步EEG、语音、面部视频与文本的融合、系统集成与情绪相关预训练；请求可用于学术研究的版本，包含原始时间戳、转写、参与者/角色ID、划分和模态完整性信息。不要声称这套数据已经具有五级心理风险标签。

应向作者确认：

- 具体release包含哪些参与者、哪些会话、哪些角色的EEG，是否所有会话均具备四种模态。
- 原始4路EEG与派生频带列的含义、采样率、同步误差及丢失片段。
- 转写是人工还是ASR、语言、词/句时间戳，以及音频中的说话人如何匹配。
- 情感相关值是否为模型估计、人工标注或自评；能否用于分类监督。
- 是否允许当前大创的训练用途、组内共享、模型权重和演示结果发布。
- 下载包大小、推荐训练/验证/测试划分以及是否有精简版本。

不能将论文中14个“有效列”直接说成14个独立原始脑电电极；Muse-2原始位置为TP9、AF7、AF8、TP10。

## EAV：备选同步EEG/音频/视频

受限记录：https://zenodo.org/records/13799131

申请入口：https://forms.gle/QvFY7EAwXgsnv9bcA

以真实姓名、学校、身份和研究目的按页面流程申请。需要用户本人或团队完成信息与协议确认。

申请时优先索取42位参与者的speaking子集及匹配EEG、视频、音频、标签；原数据8,400条交互里，音频仅覆盖约4,200条说话交互。确认是否包含实际说话的带时间戳转写；只有脚本时不要假定它等于逐字实际语音。

五个标签为neutral、anger、happiness、sadness、calmness；其用途是情绪分类，不是五级风险。
